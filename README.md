# Fake News Auction

One-link classroom game for media literacy.

## Deploy on Netlify
1. In Netlify choose **Add new project → Import an existing project**.
2. Choose GitHub and select this repository.
3. Keep the default build settings.
4. Deploy.
5. Open the public Netlify URL. Everyone uses that same link.
6. Host clicks **Host**; students click **Player**.

The game uses Netlify Functions + Netlify Blobs for shared state, so do not use a static drag-and-drop deploy.
